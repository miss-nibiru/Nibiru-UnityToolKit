# Changelog

## 0.3.2

- Moved the builder to `Tools > Miss Nibiru` with the other toolkit tools.

## 0.3.1

- Replaced unsupported `Event.actionKey` calls with Unity modifier flags.
- Made interpolated strings compatible with Unity's C# 9 compiler.

## 0.3.0

- Added generic spawnable, catalog, formation and layout ScriptableObjects.
- Added exact XY and XZ grid-to-world spawning to `WaveRunner`.
- Added the three-panel Wave Layout Builder and formation mini-grid designer.
- Added drag-and-drop placement, multi-selection, duplication, movement, Undo,
  wave management, zoom and pan.
- Added Scene-view grid and placement previews.
- Added validation, spawn statistics, active-enemy budgets and built-in FAQ.
- Added runtime, footprint, overlap, calculator and editor validation tests.
- Preserved the original `WaveData` and `ISpawnPointProvider` workflow.
